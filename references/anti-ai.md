# 去 AI 味检查清单

## 必杀列表（出现即改）

| AI 病症 | 症状 | 治法 |
|---------|------|------|
| 排比癌 | "他是…，他是…，他更是…" | 砍掉，留一个最狠的 |
| 转折词依赖 | 每段开头"然而""不过""事实上" | 删掉，直接写下一个动作 |
| 形容词堆砌 | "她那双明亮而深邃的眼眸中闪烁着坚定而温柔的光芒" | 换成一个动作："她盯着我，没眨眼" |
| 总结癖 | 段尾总结本段含义 | 删掉，读者不傻 |
| 万能感叹 | "这一刻，他终于明白了…" | 用动作/对话暗示，别直说 |
| 旁白解释 | 括号里解释角色心理 | 让读者自己猜 |
| 语气统一 | 所有角色说话像同一个人 | 给每个角色设定：用词范围、句子长度、口头禅 |
| 滥用"不禁" | "他不禁想到""她不禁笑了" | 直接写"他想到""她笑了"，或换成动作 |
| 鸡汤尾巴 | 结尾升华人生道理 | 砍掉。故事讲完就停 |

## 对话去味

### 坏（AI 味）
```
"我认为我们应该重新审视这个问题，"他语重心长地说道，"毕竟每个人都有自己的难处。"
```

### 好（人味）
```
"算了。"他把烟摁灭，"你知道老张家那事吧？一个道理。"
```

### 要点
- 人说话会省略、会跑题、会答非所问
- 潜台词 > 台词（说的和想的不一样才有张力）
- 加入打断、沉默、岔开话题
- 每个角色的信息量不同（有人知道真相有人不知道）

## 叙述去味

### 坏
```
阳光透过窗户洒进来，在地板上形成一片金色的光斑。她站在光影中，显得格外美丽动人。这是一个充满希望的早晨。
```

### 好
```
窗帘没拉严，一条光正好切在她脸上。她眯着眼没动，手里的杯子歪了，咖啡顺着手指往下淌。
```

### 要点
- 选择一个不完美的细节，比一百个漂亮形容词管用
- 动词 > 形容词 > 副词
- 写角色注意到的东西，不写全景描述
- 允许句子长短不一，节奏不均匀

## 情感去味

核心原则：**越重要的情感，越要轻描淡写。**

- 悲伤 → 不写"泪流满面"，写一个无关紧要的小动作（反复叠衣服、数地砖）
- 愤怒 → 不写"怒火中烧"，写异常的平静（声音突然轻了、笑了）
- 爱意 → 不写"深深爱着"，写一个只有两人懂的细节

## 自检流程

写完一段后快速过一遍：
1. 有没有连续两个以上形容词修饰同一个名词？→ 砍
2. 有没有段首转折词？→ 删或换
3. 角色对话能不能区分谁说的（遮住名字）？→ 不能就改
4. 段尾有没有"画外音"式总结？→ 砍
5. 大声读一遍，别扭的地方就是 AI 味
