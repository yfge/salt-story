# 去 AI 味检查清单（强化版）

## 第一层：基础病症（出现即改）

| AI 病症 | 症状 | 治法 |
|---------|------|------|
| 排比癌 | "他是…，他是…，他更是…" | 砍掉，留一个最狠的 |
| 转折词依赖 | 每段开头"然而""不过""事实上" | 删掉，直接写下一个动作 |
| 形容词堆砌 | "她那双明亮而深邃的眼眸中闪烁着坚定而温柔的光芒" | 换成一个动作："她盯着我，没眨眼" |
| 总结癖 | 段尾总结本段含义 | 删掉，读者不傻 |
| 万能感叹 | "这一刻，他终于明白了…" | 用动作/对话暗示，别直说 |
| 旁白解释 | 括号里解释角色心理 | 让读者自己猜 |
| 语气统一 | 所有角色说话像同一个人 | 给每个角色设定：用词范围、句子长度、口头禅 |
| 滥用"不禁" | "他不禁想到""她不禁笑了" | 直接写"他想到""她笑了"，或换成动作 |
| 鸡汤尾巴 | 结尾升华人生道理 | 砍掉。故事讲完就停 |
| 完美长句 | 每句话都语法完整、逻辑清晰 | 加入残句、口语、省略 |

## 第二层：隐藏 AI 特征（更致命，因为不容易察觉）

### 1. 节奏均匀
**症状**：每段差不多长，每句差不多长，读起来像节拍器。
**治法**：
- 刻意制造段落长短差异（有的段只有一句话，有的段8-10句）
- 句子长度在5字到50字之间随机波动
- 偶尔来一段只有三个字的段落："操。""完了。""不对。"

### 2. 情感表达太"正确"
**症状**：悲伤的时候写悲伤的反应，愤怒的时候写愤怒的反应。很合理，但太合理了。
**治法**：
- 真人在极端情绪下的反应往往是"错位"的：至亲去世时在纠结午饭吃什么；被劈腿后发现自己在意的是那条围巾还在他那里
- 写一个"不应该"有的反应，比写十个"应该"有的反应更像人

### 3. 过度的因果链
**症状**：每个事件都有清晰的因果关系，每段都在推进剧情。
**治法**：
- 加入与剧情无关的闲笔（角色注意到的无关细节、突然的回忆、对食物/天气的吐槽）
- 允许"死线索"——前面提到的某个细节最后没用上，就像真人写作中的随机笔触

### 4. 信息密度太高
**症状**：每句话都携带新信息，没有"浪费"的文字。
**治法**：
- 真人写小说有"呼吸"的段落——不推进剧情，只是让读者喘口气
- 角色之间的闲聊（不涉及主线的日常对话）
- 环境描写中的无用细节（"对面奶茶店换了招牌，原来叫什么来着"）

### 5. 人物行为太理性
**症状**：角色做的每个决定都合理、有逻辑。
**治法**：
- 让角色做蠢事（明知不该打那个电话还是打了；该报警但先自己去查了）
- 让角色有小毛病（总是忘带钥匙、说话爱加"我跟你说"、紧张的时候抖腿）

### 6. 叙述视角太客观
**症状**：第一人称叙述但像上帝视角一样面面俱到、观察敏锐。
**治法**：
- 第一人称叙述者应该有盲区（注意不到某些明显的事）
- 应该有偏见（对某些角色的描述带有主观色彩）
- 应该会跑题（讲着讲着突然扯到别的事上去）

## 对话去味（强化版）

### 坏（AI 味）
```
"我认为我们应该重新审视这个问题，"他语重心长地说道，"毕竟每个人都有自己的难处。"
```

### 好（人味）
```
"算了。"他把烟摁灭，"你知道老张家那事吧？一个道理。"
```

### 更好（有性格的人味）
```
"行了行了别说了，"她筷子往桌上一拍，"你是不是觉得我傻？我告诉你我就是傻。我他妈就是信了。你满意了？"
```

### 对话 DNA 模板
每个角色写之前必须定义：
- **用词档次**：文雅/普通/粗糙/混搭
- **句子平均长度**：短句型（5-10字）/ 中等（10-20字）/ 长句型（20+字）
- **口头禅**：1-2个常用语（"我跟你说""你懂我意思吧""得了吧""行吧"）
- **说话习惯**：爱打断别人 / 总是答非所问 / 说话前会"嗯"一下 / 爱反问

## 叙述去味

### 坏
```
阳光透过窗户洒进来，在地板上形成一片金色的光斑。她站在光影中，显得格外美丽动人。这是一个充满希望的早晨。
```

### 好
```
窗帘没拉严，一条光正好切在她脸上。她眯着眼没动，手里的杯子歪了，咖啡顺着手指往下淌。
```

### 更好
```
窗帘又没拉好——这破房子窗帘杆歪的，怎么拉都有条缝。光正好照她脸上，她也不躲，就眯着眼坐那儿，杯子早歪了。我看见咖啡顺着她手指往下流的时候想说来着，后来想想算了。
```

### 要点
- 选择一个不完美的细节，比一百个漂亮形容词管用
- 动词 > 形容词 > 副词
- 写角色注意到的东西，不写全景描述
- 允许句子长短不一，节奏不均匀
- **加入叙述者的主观吐槽和联想**

## 情感去味

核心原则：**不是"越重要越轻描淡写"，而是"情感表达要错位"。**

- 悲伤 → 可以写"泪流满面"——但前提是角色因为一个很小的事哭（不是因为大事本身，而是某个细节触发了情绪）
- 愤怒 → 可以写发飙——但发飙的内容和真正气的事情不同（对着快递员发火但其实是因为老公出轨）
- 爱意 → 不写"我爱你"，写一个只有当事人懂的日常细节

**关键：真人的情绪是混乱的、矛盾的、不合逻辑的。** AI 的情绪总是对应正确的刺激。

## 终极自检流程

写完全文后：
1. **随机抽3段**，大声读出来——别扭的地方就是AI味
2. **检查前5段**——有没有任何一段可以和另一段互换位置而不违和？如果可以，说明段落缺乏个性
3. **统计句子长度**——如果大部分句子在15-25字之间，节奏太均匀了
4. **数一下"的"字**——每句话超过2个"的"就要改
5. **找"然而/但是/不过/事实上"**——全文不超过3个
6. **找排比结构**——出现一次都要改
7. **看结尾**——最后一段是不是在"升华"？如果是，删掉
8. **AI检测模拟**——问自己：如果我是编辑，看到这篇稿子，会不会第一反应是"AI写的"？如果有1%的可能，就要改
