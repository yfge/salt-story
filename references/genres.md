# 盐选热门题材与反转类型库

## 五大热门赛道

### 1. 婚恋情感（最大流量池）
**核心冲突**：信任崩塌、身份错位、迟来的真相
**经典设定**：
- 闪婚对象有秘密身份（隐藏富豪/卧底/前科）
- 完美婚姻背后的交易
- 前任重逢引爆旧秘密
**读者画像**：25-40 女性为主，要的是情感张力不是甜宠

### 2. 职场权谋
**核心冲突**：利益博弈、背叛与结盟、小人物逆袭
**经典设定**：
- 新人发现公司核心秘密
- 被裁员后发现自己是弃子/棋子
- 上司和下属互换身份
**要点**：职场细节要真实（KPI、汇报、邮件用语），假了就出戏

### 3. 悬疑推理
**核心冲突**：真相多层、谁在说谎、叙述者不可靠
**经典设定**：
- 密室/封闭空间（电梯、海岛、暴雪山庄）
- 所有人都有动机
- 视角人物本身是凶手/帮凶（但读者最后才知道）
**要点**：逻辑必须严密，不能靠巧合收尾

### 4. 家庭伦理
**核心冲突**：代际矛盾、重男轻女、遗产争夺、认亲
**经典设定**：
- 抱错孩子二十年后相认
- 临终遗嘱引爆家庭暗流
- "最不被看好的孩子"成了唯一靠谱的
**要点**：情感要克制，越撕裂越要写得平静

### 5. 奇情/脑洞
**核心冲突**：时间循环、平行世界、都市传说
**经典设定**：
- 每天醒来少一个人
- 收到未来自己的信
- 某个 App 能看到别人的秘密
**要点**：设定要简单（一句话说清规则），不要搞复杂世界观

## 反转类型库

### A 级反转（改变整个故事的意义）
1. **叙述者不可靠** — 我一直在骗你（视角人物隐瞒了关键信息）
2. **身份互换** — A 其实是 B（凶手是侦探、受害者是加害者）
3. **时间骗局** — 不是你以为的时间线（插叙、倒叙制造的错觉）
4. **善恶倒转** — 好人是坏人，坏人在保护你

### B 级反转（改变某条线的理解）
1. **动机反转** — 他这么做不是因为恨，是因为爱
2. **关系反转** — 陌生人其实认识你很久了
3. **能力反转** — 看起来最弱的人掌握关键牌
4. **结果反转** — 以为赢了其实输了（或反过来）

### C 级反转（增加层次感的小转折）
1. **信息差揭露** — 读者知道但角色不知道（反之亦然）
2. **伏笔回收** — 开头无关紧要的细节突然变关键
3. **第三方介入** — 以为是两个人的事，实际还有人在暗处
4. **反常行为解释** — 前面莫名其妙的行为终于有了合理解释

## 人设模板

### 主角类型
- **隐忍型**：能力强但一直在压着，爆发时最爽（适合逆袭线）
- **天真型**：真诚到让人心疼，被利用后觉醒（适合成长线）
- **灰色型**：亦正亦邪，动机模糊，最后揭底（适合悬疑线）
- **破碎型**：带着创伤行动，行为逻辑和常人不同（适合情感线）

### 反派/对手
- 永远不要写纯粹的坏人，给他一个让读者犹豫的理由
- 最好的反派是"如果我在他的处境，我可能也会这么做"
- 对手的智商至少和主角持平，碾压感要靠信息差而非智商差

## 付费墙设置建议

最佳断点：
1. 第一个大秘密刚露出冰山一角
2. 主角做出了一个不可逆的决定
3. "我推开门，看到了——"（感官中断）
4. 已知信息突然自相矛盾

**原则**：免费部分要让读者建立情感投入（关心角色），付费部分才放核心反转和真相。
